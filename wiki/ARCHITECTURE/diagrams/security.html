Failure ownership

Expected

Typed capability failures are mapped to the channel and are not reported as crashes.

Unexpected

Capture once at the owning boundary, redact sensitive data, then return a safe result.

Non-negotiable checks

Identity

Shared auth proves provider userId; the identity capability owns product profile and role.

Scope

Check role, tenant, and resource ownership before provider access.

Secrets

Server env and service clients never enter browser-capable import graphs.

Streaming

Before commit, map to status. After commit, emit an in-band error event.
