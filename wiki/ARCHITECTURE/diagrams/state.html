State follows the runtime that owns its lifecycle.

The same entity can appear in several caches. Keys, invalidation, freshness, and hydration remain explicit at each tier.

Provider data Supabase or external API is the durable source.

Local UI state Open panels, draft values, selection, and transient interaction.

Ownership

Query keys

Live in runtime-neutral query-cache.ts; RSC and client code import the same keys.

Server tags

Exist only when a read calls cacheTag; inert invalidation is forbidden.

Prefetch

RSC code calls rsc.ts; browser code calls GET. They share behavior, not transport.

Realtime

Shared transport emits provider events; app composition maps them to public capability keys.

Do not hide invalidation in a generic global helper. A mutation should make every affected cache tier visible in its owning capability.
