Walks the same state categories as .claude/rules/data-state.md: Server State, Global State, Form State, Component UI, and Page UI. The two right-hand leaves under "server-owned, no client interactivity" reflect a real, current fact about this codebase rather than a generic pattern — see the callout below.

Grounded in fact, not a generic template: this app has no page/layout that reads a use-case or repository directly — every read, client-triggered or SSR, goes through queryClient.prefetchQuery({ queryFn: () => someAction() }) in ui/server-state/{work-items,labels}/prefetch.ts, hydrated via <HydrationBoundary> in (protected)/layout.tsx and the admin/work-items pages. The right-hand "Direct RSC props" leaf is the boundary that would matter if a future page added a direct DAL read — it is not a pattern in active use (T4, Part B.3).
URL-shareable filters — not implemented yet: before escalating a Page UI state to Context or a store, ask whether it should be bookmarkable/shareable via the URL. Today, WorkItemListParams (search, labelId, priorityOnly, status, page, pageSize) is passed as plain function/component arguments, not read from searchParams — this template does not currently sync list filters to the URL.

State Decision Table (mirrors .claude/rules/data-state.md)

State Type Tool Location Example
Server State TanStack Query ui/server-state/ User data, work items
Global State React Context ui/providers/ User, theme, locale
Form State Mantine Forms + Valibot Component-local Edit forms, filters
Component UI useState/useReducer Component-local Modals, dropdowns, toggles
Page UI useState/useReducer Feature-local hook Filters, tabs, layout mode

Rules: React Query hooks are feature-local integration code that may call inbound adapters or safe feature fetchers — UI must not call outbound adapters directly. Feature-local actions.ts files are for thin direct Server Action wrappers without query semantics (blur-time uniqueness checks, shared form submit helpers) — they must not hold query keys, optimistic updates, or cache invalidation.
