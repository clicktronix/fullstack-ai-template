Forbidden direction, explicit: src/use-cases/** must never import @/adapters/outbound/** directly (③ above). ESLint's no-restricted-imports blocks it, and the real code is stricter than the rule requires — zero infrastructure or outbound imports were found anywhere in src/use-cases/ (T1 audit). Use-cases only ever see the port type (① import type, erased at runtime) and receive a concrete implementation as a plain function argument, injected by Inbound (② — a runtime call on an object, not an import).
Documented exception: ui/server-state/auth-events.ts and ui/server-state/realtime.ts import two outbound Supabase modules directly — both are the anon-key browser client (adapters/supabase/client.ts), never a server/service-role client. This is the one sanctioned "client-safe outbound helper" exception (T1), not a boundary violation.
