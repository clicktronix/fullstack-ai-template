Capability ownership is the primary boundary.

A product capability owns its language, behavior, runtime adapters, and UI. Other modules see narrow root surfaces, not its folders.

Ownership rules

Inside a capability

Private segments can evolve together. Create only the segments the behavior needs.

Across capabilities

Import root public surfaces. An orchestrator capability owns multi-capability behavior.

Shared code

Promote only after two consumers share meaning, runtime, ownership, and change cadence.

Application behavior

Keep an operation only when deleting it moves meaningful policy into callers.
